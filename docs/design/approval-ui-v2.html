Approval Panel v2 — Compact Redesign

v1 feedback: too big, too busy. Fix: everything collapses to a single row by default (icon + one-line truncated command + Skip/Allow) — no wrapping, no separate footer row, no loud badge. Details (full command, "always allow") only appear if you explicitly expand.

1. Default state — single row, always

Long commands truncate with an ellipsis instead of wrapping to 2 lines and growing the card.

create aaa12333333.txt file
printf '%s' "This is aaa12333333.txt" > aaa12333333.txt && echo Created…
Steer the agent…

2. Expanded state — click the chevron

Full command + "always allow" only show up here, never cluttering the default row.

create aaa12333333.txt file
printf '%s' "This is aaa12333333.txt" > aaa12333333.txt && echo Created… 
printf '%s' "This is aaa12333333.txt" > aaa12333333.txt && echo Created aaa12333333.txt && sed -n '1,200p' aaa12333333.txt
Steer the agent…

3. High-impact indicator — no separate badge

Instead of a "REVIEW CAREFULLY" pill competing for attention, a thin left accent bar (warning color) on bash/write/edit calls — visible but quiet.

Routine (read/grep/find/ls)

grep "TODO" src/**/*.ts

High-impact (bash/write/edit)

rm -rf ./dist && npm run build

4. Skip/denial notice — quiet, not alarming

v1 problem: reused the raw chat-line.is-error style (danger-red monospace paragraph) for what's really just a user decision, not a bug/crash. It reads like something broke. Fix: match the existing timeline row language (dot + label) with a neutral gray "skipped" dot, not danger red -- same visual family as a tool call, just a different outcome.

Before (v1)

delete the old backup folder
"bash" was denied -- stopping this turn.
Message the agent…

After (v2)

delete the old backup folder
Skipped bash · rm -rf ./backup-old turn stopped
Message the agent…

5. What changed vs. v1

• Single row instead of a 2-row title + full-width footer  ·  long text truncates instead of wrapping  ·  "REVIEW CAREFULLY" pill replaced with a quiet left accent bar  ·  keyboard hint moved onto the Allow button itself ("Allow ↵") instead of a separate row  ·  "Always allow" and the raw command both moved behind the expand chevron  ·  skip/denial notice now a quiet neutral timeline-style row instead of a red monospace error paragraph.
